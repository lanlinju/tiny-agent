# Agent 工具文档入口

本文档集用于先完成架构设计与阶段边界，不包含实现代码。

## 已确认决策

- 目标用户：开发者本地工具，这是默认假设，可改。
- MVP 场景：文件操作。
- 运行形态：本地进程为主，服务端能力作为本地 `server` 抽象，这是默认假设，可改。
- 模型接入：多家兼容；MVP 先以 OpenAI-compatible 接口落地，同时保留 provider 切换规范。
- 前端优先级：`CLI + Web` 同步规划协议和交互边界。
- 插件系统：插件可后置；先文档化受控扩展点，不进入阶段 1 实现，这是默认假设，可改。
